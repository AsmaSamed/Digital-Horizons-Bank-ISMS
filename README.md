# نظام إدارة أمن المعلومات – بنك الآفاق الرقمية
# Information Security Management System – Digital Horizons Bank



## نبذة عن المشروع | Project Overview  
المعلومات (ISMS) في بنك الآفاق الرقمية وفق متطلبات ISO/IEC 27001:2022.



## 🎯 أهداف المشروع | Project Objectives  
يهدف المشروع إلى:  
•  	تحديد نطاق نظام إدارة أمن المعلومات في بنك الآفاق الرقمية.  
•	تحديد وحصر الأصول المعلوماتية والتقنية ذات العلاقة.  
•	تحديد وتقييم مخاطر أمن المعلومات وربطها بالأصول.  
•	تحديد إجراءات معالجة المخاطر والضوابط الأمنية المناسبة.  
•	إعداد الوثائق والسياسات والإجراءات الأساسية لنظام ISMS.  
•	دعم قياس الأداء والتدقيق الداخلي والتحسين المستمر.  
•	إعداد متطلبات استمرارية الأعمال والتعافي من الكوارث.  



## 🏦 نطاق المشروع | ISMS Scope  
يركز نطاق المشروع على المعلومات والأنظمة والموارد والعمليات المرتبطة بالخدمات المصرفية وأمن المعلومات، بما في ذلك:  
•	بيانات العملاء.  
•	بيانات الموظفين.  
•	المعلومات المالية والمحاسبية.  
•	معلومات الخزينة.  
•	التطبيقات والأنظمة المصرفية.  
•	قواعد البيانات.  
•	كود المصدر.  
•	الشبكات وإعدادات الأمن.  
•	السجلات الأمنية وسجلات الأنظمة.  
•	تقارير الثغرات الأمنية.  
•	الشهادات والمفاتيح التشفيرية.  
•	النسخ الاحتياطية وموارد التعافي من الكوارث.




## 📄 وثائق نظام إدارة أمن المعلومات | ISMS Documents

يتضمن المشروع مجموعة من الوثائق المترابطة، ومن أهمها:
| الوثيقة | الغرض |
| :--- | :--- |
| ISMS Scope | تحديد نطاق نظام إدارة أمن المعلومات |
| Information Security Policy | تحديد التوجه العام ومتطلبات أمن المعلومات |
| Risk Assessment | تحديد وتقييم مخاطر أمن المعلومات |
| Risk Treatment | تحديد إجراءات معالجة المخاطر |
| Statement of Applicability | توثيق الضوابط القابلة للتطبيق ومبرراتها |
| Risk Methodology | تحديد منهجية تقييم وإدارة المخاطر |
| Risk Appetite | تحديد مستوى المخاطر المقبول |
| Information Security Objectives | تحديد أهداف أمن المعلومات |
| Asset Inventory | حصر الأصول المعلوماتية |
| Acceptable Use Policy | تحديد قواعد الاستخدام المقبول |
| Incident Response Procedure | تنظيم الاستجابة للحوادث الأمنية |
| Internal Audit Report | تقييم مدى مطابقة وفعالية ISMS |
| Security Operating Procedures | تنظيم العمليات والإجراءات الأمنية |
| Performance Report | متابعة وقياس أداء ISMS |
| Secure Configuration Baseline | تحديد إعدادات التكوين الأمني المطلوبة |
| BCP & Disaster Recovery | دعم استمرارية الأعمال والتعافي من الكوارث |

## ⚠️ أهم المخاطر التي تم أخذها في الاعتبار | Key Risk Areas  

يتناول المشروع مخاطر مرتبطة بالبيئة المصرفية الرقمية، ومن أبرزها:  
•	التصيد الإلكتروني Phishing.  
•	برمجيات الفدية Ransomware.  
•	هجمات حجب الخدمة DDoS.  
•	التهديدات الداخلية Insider Threats.  
•	مخاطر سلسلة التوريد Supply Chain Risks.  
•	أخطاء إعدادات الشبكة والأمن.  
•	فقدان الأجهزة التي تحتوي على بيانات حساسة.  
•	انتهاء الشهادات الرقمية.  
•	الصلاحيات الزائدة.  
•	الثغرات الأمنية غير المعالجة.
